# Scripts SQL — TuRecorrido

Orden de ejecución recomendado:

1. `base_de_datos_tablas.sql`
2. `funcion1_fn_dia_semana_actual.sql`
3. `package1_pkg_telemetria.sql`
4. `funcion2_fn_velocidad_promedio.sql`
5. `package2_pkg_tarifas.sql`
6. `funcion3_fn_calcular_tarifa.sql`
7. `procedimiento1_sp_evaluar_reincidencia.sql`
8. `procedimiento2_sp_revisar_reincidencia_diaria.sql`
9. `trigger1_trg_ticket_estado_inicial.sql`
10. `trigger2_trg_ticket_valida_cambio.sql`
11. `trigger3_trg_ticket_aviso_insercion.sql`

También puedes ejecutar `fullbd.sql`, que contiene todo en ese mismo orden.

Notas:

- Los IDs son `NUMBER GENERATED BY DEFAULT AS IDENTITY` (Oracle 12c o superior).
- `funcion2` y `funcion3` son wrappers públicos de `pkg_telemetria` y `pkg_tarifas`; requieren que los packages estén creados primero.
- Para ver la salida de `DBMS_OUTPUT`, ejecutar `SET SERVEROUTPUT ON SIZE UNLIMITED`.
